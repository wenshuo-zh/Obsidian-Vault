1. 内存特点：链表在内存不是连续分布的，通过指针链接在内存的各个节点
2. 复杂度：插入、删除时间复杂度O(1)，查询时间复杂度O(n)
3. 链表的长度可以是不固定的，并且可以动态增删， 适合数据量不固定，频繁增删，较少查询的场景

### 构造链表（尾插法，头插法）
#### 节点定义
```cpp
struct ListNode{
	int val;
	ListNode *next;
	ListNode():val(0),next(nullptr){}
};
```
#### 尾插法
具体操作过程：创建一个虚头节点（不存放数据，方便操作），定义中间变量temp，初始等于dummyHead。循环链表长度次数：==创建节点p，cin值val，将temp的下一项指向p，p的下一项指空，更新temp = temp->next（即指向p）==，最后返回头节点（虚头节点的下一项）。
```cpp
ListNode* creatList(int n){
	ListNode* dummyHead = new ListNode();
	dummyHead->next = nullptr;
	ListNode* temp = dummyHead;
	while(n--){
		ListNode* p = new ListNode();
		cin >> p->val;
		temp->next = p;
		p->next = nullptr;
		temp = temp->next;
	}
	ListNode* realNode = dummyHead->next;
	delete dummyHead;
	return realNode;
}
```
#### 头插法
p的下一项指向头节点（p成为新的头节点），虚头节点的下一项指向p
```cpp
ListNode* creatList(int n){
	ListNode* dummyHead = new ListNode;
	dummyHead->next = nullptr;
	while(n--){
		ListNode* p = new ListNode;
		cin >> p->val;
		p->next = dummyHead->next;
		dummyHead->next = p;
	}
	ListNode* realHead = dummyHead->next;
	delete dummyHead;
	return realHead;
}
```
