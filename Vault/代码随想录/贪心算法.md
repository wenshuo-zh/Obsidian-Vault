## 分发饼干
从小到大遍历饼干，和当前胃口最小的孩子对比，如果能吃饱就下一个饼干和孩子，如果吃不饱就把这个饼干扔掉换下一个饼干
局部贪心👇
	一块饼干，如果连**当前剩下胃口最小**的孩子都喂不饱，那剩下所有孩子胃口都比他更大，这块饼干谁都喂不了 → **直接丢弃这块饼干**
```cpp
class Solution {
public:
    int findContentChildren(vector<int>& g, vector<int>& s) {
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());
        int index = 0;
        for(int i = 0; i < s.size(); i++){
            if(index < g.size() && g[index] <= s[i]){
                index++;
            }
        }
        return index;
    }
};
```
## 摆动序列
数据差作为坡度，遇到三个点是连续单调的就不符合，所以做删除，保留所有峰值，即是最大摆动序列
局部贪心👇
	单调区间**直接取端点作为拐点**，不尝试中间点；每一步局部最优，最终得到全局最长。
```cpp
class Solution {
public:
    int wiggleMaxLength(vector<int>& nums) {
        if(nums.size() <= 1)return nums.size();
        int cur = 0;
        int pre = 0;
        int res = 1;
        for(int i = 0; i < nums.size() - 1; i++){
            cur = nums[i + 1] - nums[i];
            if(cur == 0)continue;
            if((pre <= 0 && cur > 0) || pre >= 0 && cur < 0){
                res++;
            }
            pre = cur;
        }
        return res;
    }
};
```
## 最大子数组和
```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int res = nums[0];
        int count = 0;
        for(int i = 0; i < nums.size(); i++){
            count = max(nums[i], count + nums[i]);
            res = max(count, res);
        }
        return res;
    }
};
```
## 买卖股票的最佳时期II
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int res = 0;
        for(int i = 0; i < prices.size() - 1; i++){
            res += max(prices[i + 1] - prices[i], 0);
        }
        return res;
    }
};
```
