
## 哈希表基础
1. 哈希表通过哈希函数把 **key 映射到数组下标**，用空间换取查询速度。
2. 不同 key 得到相同下标时发生**哈希冲突**，常见解决方式：拉链法、线性探测法。
3. 平均情况下，插入、查找、删除的时间复杂度为 O(1)；极端冲突时可能退化为 O(n)。

| 容器              | 适用场景           | 特点              |
| --------------- | -------------- | --------------- |
| `int count[26]` | key 范围固定，如小写字母 | 最快，直接用下标计数      |
| `unordered_set` | 去重、判断某个值是否存在   | 只存 key          |
| `unordered_map` | 统计频率、记录元素位置    | 存 key-value 键值对 |

- `unordered_set`、`unordered_map` 不保证遍历顺序，平均查询 O(1)。
- `set`、`map` 底层是红黑树，元素有序，查询 O(log n)。
- `map[key]` 在 key 不存在时会创建默认值；只查询时优先用 `find()` 或 `count()`。

## 有效的字母异位词
两个字符串中每个字母出现次数相同就是字母异位词。题目只含小写字母，直接用 `int arr[26]` 计数，不需要哈希表。

- 遍历 `s` 加一、遍历 `t` 减一，最后只要有位置不为 0 就不是异位词。
- 下标通过 `s[i] - 'a'` 得到；该做法只适用于字符范围固定的场景。
```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        int arr[26] = {0};
        for(int i = 0; i < s.size(); i++)arr[s[i] - 'a']++;
        for(int i = 0; i < t.size(); i++)arr[t[i] - 'a']--;
        for(int i = 0; i < 26; i++)if(arr[i] != 0)return false;
        return true;
    }
};
```
## 两个数组的交集
交集要求结果**不重复**，用 `unordered_set` 保存第一个数组，再遍历第二个数组判断是否存在。

- 结果也用集合保存，避免第二个数组中有重复元素时重复加入。
- 返回前将集合转为 `vector`；结果顺序不作要求。
```cpp
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        unordered_set<int> set;
        unordered_set<int> ans;
        for(auto it : nums1){
            set.insert(it);
        }
        for(auto it : nums2){
            if(set.count(it))ans.insert(it);
        }
        return vector<int>(ans.begin(), ans.end());
    }
};
```
## 两数之和
用哈希表记录已经遍历过的数及其下标：`key` 是元素值，`value` 是下标。

- 先查找 `target - nums[i]` 是否出现过，再记录当前元素，避免同一个元素被使用两次。
- 找到补数后直接返回两个下标，时间复杂度 O(n)，空间复杂度 O(n)。
```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int,int>map;
        for(int i = 0; i< nums.size(); i++){
            auto it = map.find(target - nums[i]);
            if(it != map.end())return{it->second,i};
            map[nums[i]] = i;
        }
        return {};
    }
};
```
