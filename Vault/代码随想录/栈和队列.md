
## 用栈实现队列
用两个栈，一个in栈一个out栈，in负责入队out负责出队，out为空时直接把in中元素倒入out，就能实现队列的先入先出
```cpp
class MyQueue {
public:
    stack<int>stIn;
    stack<int>stOut;

    MyQueue() {

    }

    void push(int x) {
        stIn.push(x);
    }

    int pop() {
        if(stOut.empty()){
            while(!stIn.empty()){
                stOut.push(stIn.top());
                stIn.pop();
            }
        }
        int ans = stOut.top();
        stOut.pop();
        return ans;
    }

    int peek() {
        if(stOut.empty()){
            while(!stIn.empty()){
                stOut.push(stIn.top());
                stIn.pop();
            }
        }
        return stOut.top();
    }

    bool empty() {
        return stOut.empty() && stIn.empty();
    }
};
```
时间复杂度：`push` 为 `O(1)`；`pop` 和 `peek` 单次最坏为 `O(n)`，均摊为 `O(1)`。
空间复杂度：`O(n)`。

## 用队列实现栈

```cpp
class MyStack {
public:
    queue<int>q1;
    queue<int>q2;
    MyStack() {

    }
    void push(int x) {
        q1.push(x);
    }

    int pop() {
        while(q1.size() > 1){
            q2.push(q1.front());
            q1.pop();
        }
        int temp = q1.front();
        q1.pop();
        q1 = q2;
        while(!q2.empty())q2.pop();
        return temp;
    }

    int top() {
        while(q1.size() > 1){
            q2.push(q1.front());
            q1.pop();
        }
        q2.push(q1.front());
        int temp = q1.front();
        q1 = q2;
        while(!q2.empty())q2.pop();
        return temp;
    }

    bool empty() {
        return q1.empty();
    }
};
```
时间复杂度：`push` 为 `O(1)`；`pop` 和 `top` 为 `O(n)`；`empty` 为 `O(1)`。
空间复杂度：`O(n)`。

## 有效的括号
遍历字符串，如果是左括号就将对应的右括号入栈，如果是右括号就去看栈顶是不是一样的右括号，是就出栈，不是就无效
```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char>st;
        for(char ch : s){
            if(ch == '(')st.push(')');
            else if(ch == '{')st.push('}');
            else if(ch == '[')st.push(']');
            else{
                if(st.empty() || st.top() != ch)return false;
                st.pop();
            }
        }
        return st.empty();
    }
};
```
时间复杂度：`O(n)`，每个括号最多入栈、出栈一次。
空间复杂度：`O(n)`，最坏情况下所有字符都是左括号。

遇到右括号时，要先判断栈是否为空，再访问栈顶；遍历结束后栈必须为空，才说明括号完全匹配。
## 删除字符串中所有相邻重复项
```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        stack<char> st;
        for(char ch : s){
            if(st.empty())st.push(ch);
            else {
                if(ch == st.top())st.pop();
                else st.push(ch);
            }
        }
        string ans;
        while(!st.empty()){
            ans += st.top();
            st.pop();
        }
        reverse(ans.begin(),ans.end());
        return ans;
    }
};
```
时间复杂度：`O(n)`，每个字符最多入栈、出栈一次，最后反转一次。
空间复杂度：`O(n)`。
