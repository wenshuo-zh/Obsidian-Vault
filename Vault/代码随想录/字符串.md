## 反转字符串

双指针

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0, right = s.size() - 1;
        while(left < right){
            swap(s[left],s[right]);
            left++;
            right--;
        }
    }
};
```

## 反转字符串II

关键注意点：
- 步长直接设置成 `2 * k`。
- `right = min(i + k - 1, n - 1)` 可以处理剩余长度小于 `k` 的情况。

```cpp
class Solution {
public:
    string reverseStr(string s, int k) {
        int n = s.size();
        for(int i = 0; i < n; i += 2 * k){
            int left = i, right = min(i + k - 1, n - 1);
            while(left < right){
                swap(s[left],s[right]);
                left++;
                right--;
            }
        }
        return s;
    }
};
```

## 替换数字

每个数字替换为 `number`，长度从 1 变为 6，因此每个数字会让字符串长度增加 5。

关键注意点：
- 第一遍统计数字个数，再 `resize` 扩容，避免边遍历边扩容。
- `oldIndex` 指向原字符串末尾，`newIndex` 指向扩容后字符串末尾。
- 从后往前填充，避免覆盖还未处理的原字符。
- `newIndex` 从后往前移动，因此按 `r e b m u n` 的顺序写入，最终字符串中才是 `number`。

时间复杂度：`O(n)`

空间复杂度：`O(1)`（不计字符串扩容）

```cpp
#include <iostream>
#include <string>
using namespace std;

int main(){
    string s;
    cin >> s;
    int count = 0;
    for(char ch : s){
        if(ch >= '0' && ch <= '9'){
            count++;
        }
    }
    int oldIndex = s.size() - 1;
    s.resize(s.size() + count * 5);
    int newIndex = s.size() - 1;
    while(oldIndex >= 0){
        if(s[oldIndex] >= '0' && s[oldIndex] <= '9'){
            s[newIndex--] = 'r';
            s[newIndex--] = 'e';
            s[newIndex--] = 'b';
            s[newIndex--] = 'm';
            s[newIndex--] = 'u';
            s[newIndex--] = 'n';
            oldIndex--;
        }
        else{
            s[newIndex--] = s[oldIndex--];
        }
    }
    for(char ch : s){
        cout<<ch;
    }
    return 0;
}
```

## 反转字符串中的单词

关键注意点：
- 快慢指针去除前导、尾部和连续空格，只保留单词之间的一个空格。
- 先整体反转，再逐个单词反转，得到单词顺序反转后的结果。
- `slow` 指向下一个写入位置，最后有效字符的下标是 `slow - 1`。
- 扫描到空格时反转前一个单词；循环结束后还要单独反转最后一个单词。

时间复杂度：`O(n)`

空间复杂度：`O(1)`

```cpp
class Solution {
public:
    string reverseWords(string s) {
        int slow = 0;
        for(int fast = 0; fast < s.size(); fast++){
            if(s[fast] != ' ' || (slow != 0 && s[fast - 1] != ' ')){
                s[slow] = s[fast];
                slow++;
            }
        }
        if(slow > 0 && s[slow - 1] == ' ') slow--;
        s.resize(slow);

        int left = 0, right = slow - 1;
        while(left < right){
            swap(s[left],s[right]);
            left++;
            right--;
        }

        int start = 0;
        for(int i = 0; i < slow; i++){
            if(s[i] == ' '){
                int left = start, right = i - 1;
                while(left < right){
                    swap(s[left],s[right]);
                    left++;
                    right--;
                }
                start = i + 1;
            }
        }
        left = start, right = slow - 1;
        while(left < right){
            swap(s[left],s[right]);
            left++;
            right--;
        }
        return s;
    }
};
```

## 右旋字符串

三次反转：先整体反转，再反转前 `k` 个字符，最后反转剩余字符。

```cpp
#include <iostream>
#include <string>
using namespace std;

void flipString(int left, int right, string& s){
    while(left < right){
        swap(s[left],s[right]);
        left++;
        right--;
    }
}

int main(){
    int k;
    string s;
    cin >> k;
    cin >> s;
    int n = s.size();
    flipString(0,n - 1,s);
    flipString(0,k - 1,s);
    flipString(k,n - 1,s);
    for(char ch : s) cout << ch;
    return 0;
}
```

## 实现 strStr()

### 暴力匹配

枚举主串的每个起点，再逐个比较模式串。
时间复杂度：`O(m * n)`
空间复杂度：`O(1)`
```cpp
class Solution {
public:
    int strStr(string haystack, string needle) {
        if(needle.empty()) return 0;
        int nh = haystack.size(), nn = needle.size();
        for(int slow = 0; slow <= nh - nn; slow++){
            if(haystack[slow] == needle[0]){
                bool match = true;
                for(int fast = 0; fast < nn; fast++){
                    if(haystack[slow + fast] != needle[fast]){
                        match = false;
                        break;
                    }
                }
                if(match) return slow;
            }
        }
        return -1;
    }
};
```

### KMP

核心：主串下标 `i` 只前进；模式串下标 `j` 匹配时前进，失配时通过 `next` 回退。
`next[i]`：`needle[0...i]` 最长相同前后缀中，前缀最后一个字符的下标。
```text
needle：a  a  b  a  a  f
next： -1 0 -1 0  1 -1
```
`j = -1` 表示当前没有匹配上的前缀。`j = 1` 表示已匹配的前缀为 `needle[0...1]`，长度为 `j + 1 = 2`。
构造 `next` 的流程：
- 初始化：`j = -1`，`next[0] = -1`。
- 不同：`j = next[j]`，不断尝试更短、但仍可能匹配的前缀。
- 相同：`j++`，相同前后缀长度增加 1。
- 最后：`next[i] = j`，记录当前位置结果。
匹配时也使用相同的回退规则：
```text
相同：j++
不同：j = next[j]
i：始终由 for 循环向前，不回退
```

```cpp
class Solution {
public:
    int strStr(string haystack, string needle) {
        if(needle.empty()) return 0;
        int n = needle.size();
        vector<int> next(n, 0);
        int j = -1;
        next[0] = -1;

        // 构造 next 数组
        for(int i = 1; i < n; i++){
            while(j >= 0 && needle[i] != needle[j + 1]){
                j = next[j];
            }
            if(needle[i] == needle[j + 1]){
                j++;
            }
            next[i] = j;
        }

        // 使用 next 数组匹配
        j = -1;
        for(int i = 0; i < haystack.size(); i++){
            while(j >= 0 && haystack[i] != needle[j + 1]){
                j = next[j];
            }
            if(haystack[i] == needle[j + 1]){
                j++;
            }
            if(j == n - 1){
                return i - n + 1;
            }
        }
        return -1;
    }
};
```
时间复杂度：`O(m + n)`
空间复杂度：`O(n)`
## 重复的子字符串
kmp：
判断条件：`len` 为最小重复单元候选长度；若字符串长度 `n` 能被 `len` 整除，且 `next[n - 1] != -1`（整个字符串存在相等的前后缀），就为真。
```cpp
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        int n = s.size();
        vector<int>next(n,0);
        int j = -1;
        next[0] = -1;
        for(int i = 1; i < n; i++){
            while(j >= 0 && s[i] != s[j + 1])j = next[j];
            if(s[i] == s[j + 1])j++;
            next[i] = j;
        }

        int len = n - (next[n - 1] + 1);
        if(next[n - 1] != -1 && n % len == 0)return true;
        else return false;
    }
};
```
移动匹配：将 `s` 拼接两次，去掉首尾字符后，查找是否仍包含 `s`，避免匹配到拼接前后的原字符串。
	string::npos静态常量，代表找不到的标记
```cpp
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        string t = s + s;
        t.erase(t.begin());
	    t.pop_back();
	    return t.find(s) != string::npos;
    }
};
```
