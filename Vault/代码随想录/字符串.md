## 反转字符串
双指针
```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0,right = s.size() - 1;
        while(left < right){
            swap(s[left],s[right]);
            left++;
            right--;
        }
    }
};
```
## 反转字符串II
关键注意点：
- 步长直接设置成2k
- 用一行代码解决小于k的情况 right = min(i + k - 1, n - 1)
```cpp
class Solution {
public:
    string reverseStr(string s, int k) {
        int n = s.size();
        for(int i = 0; i < n; i += 2 * k){
            int left = i,right = min(i + k - 1, n - 1);
            while(left < right){
                swap(s[left],s[right]);
                left++;
                right--;
            }
        }
        return s;
    }
};
```
