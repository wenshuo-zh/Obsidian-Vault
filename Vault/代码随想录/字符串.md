## 反转字符串
双指针
```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0,right = s.size() - 1;
        while(left < right){
            swap(s[left],s[right]);
            left++;
            right--;
        }
    }
};
```
## 反转字符串II
关键注意点：
- 步长直接设置成2k
- 用一行代码解决小于k的情况 right = min(i + k - 1, n - 1)
```cpp
class Solution {
public:
    string reverseStr(string s, int k) {
        int n = s.size();
        for(int i = 0; i < n; i += 2 * k){
            int left = i,right = min(i + k - 1, n - 1);
            while(left < right){
                swap(s[left],s[right]);
                left++;
                right--;
            }
        }
        return s;
    }
};
```
## 替换数字

每个数字替换为 `number`，长度从 1 变为 6，因此每个数字会让字符串长度增加 5。

关键注意点：
- 第一遍统计数字个数，再 `resize` 扩容，避免边遍历边扩容。
- `oldIndex` 指向原字符串末尾，`newIndex` 指向扩容后字符串末尾。
- 从后往前填充，避免覆盖还未处理的原字符。
- `newIndex` 从后往前移动，因此按 `r e b m u n` 的顺序写入，最终字符串中才是 `number`。

时间复杂度：`O(n)`

空间复杂度：`O(1)`（不计字符串扩容）

```cpp
#include <iostream>
#include <string>
using namespace std;

int main(){
    string s;
    cin >> s;
    int count = 0;
    for(char ch : s){
        if(ch >= '0' && ch <= '9'){
            count++;
        }
    }
    int oldIndex = s.size() - 1;
    s.resize(s.size() + count * 5);
    int newIndex = s.size() - 1;
    while(oldIndex >= 0){
        if(s[oldIndex] >= '0' && s[oldIndex] <= '9'){
            s[newIndex--] = 'r';
            s[newIndex--] = 'e';
            s[newIndex--] = 'b';
            s[newIndex--] = 'm';
            s[newIndex--] = 'u';
            s[newIndex--] = 'n';
            oldIndex--;
        }
        else{
            s[newIndex--] = s[oldIndex--];
        }
    }
    for(char ch : s){
        cout<<ch;
    }
    return 0;
}
```

## 反转字符串中的单词

关键注意点：
- 快慢指针去除前导、尾部和连续空格，只保留单词之间的一个空格。
- 先整体反转，再逐个单词反转，得到单词顺序反转后的结果。
- `slow` 指向下一个写入位置，最后有效字符的下标是 `slow - 1`。
- 扫描到空格时反转前一个单词；循环结束后还要单独反转最后一个单词。
时间复杂度：`O(n)`
空间复杂度：`O(1)`
- 去空格后若末尾是空格，要先 `slow--`，再 `resize(slow)`。
```cpp
class Solution {
public:
    string reverseWords(string s) {
        // 利用快慢指针保留合理空格
        int slow = 0;
        for(int fast = 0; fast < s.size(); fast++){
            if(s[fast] != ' ' || (slow != 0 && s[fast - 1] != ' ')){
                s[slow] = s[fast];
                slow++;
            }
        }
        if(slow > 0 && s[slow - 1] == ' ') slow--;
        s.resize(slow);

        // 反转整个字符串
        int left = 0, right = slow - 1;
        while(left < right){
            swap(s[left],s[right]);
            left++;
            right--;
        }

        // 反转单词
        int start = 0;
        for(int i = 0; i < slow; i++){
            if(s[i] == ' '){
                int left = start, right = i - 1;
                while(left < right){
                    swap(s[left],s[right]);
                    left++;
                    right--;
                }
                start = i + 1;
            }
        }
        left = start, right = slow - 1;
        while(left < right){
            swap(s[left],s[right]);
            left++;
            right--;
        }
        return s;
    }
};
```
