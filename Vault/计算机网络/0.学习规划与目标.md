## 一、先建立一张基础地图

把浏览器访问网站想成“寄快递”过程：

| 层次 | 解决的问题 | 常见内容 |
| --- | --- | --- |
| 应用层 | 数据按什么格式表达 | HTTP、DNS |
| 传输层 | 两个程序如何可靠/快速地传数据 | TCP、UDP、端口 |
| 网络层 | 数据送到哪台机器 | IP、路由、ICMP |
| 链路层 | 同一局域网中如何交付 | MAC、ARP、交换机 |

一次访问大致经过：

```text
域名 -> DNS 得到 IP -> 连接目标端口 -> 发送 HTTP 请求 -> 收到 HTTP 响应
```

先记住三组容易混淆的概念：

- **IP**：找到哪台机器；**端口**：找到机器上的哪个进程/服务。
- **TCP**：可靠的字节流；**UDP**：尽力而为的数据报。
- **HTTP**：应用层的报文规则，不负责建立可靠连接；HTTP 通常运行在 TCP 之上。

## 二、学习目标

### 目标 1：能看懂一次 HTTP 请求

- 看懂请求行、请求头、空行、请求体。
- 掌握 `GET`、`POST`、`PUT`、`DELETE` 的基本用途。
- 理解 `Host`、`Content-Type`、`Content-Length`、`Cookie`、`Authorization`。
- 认识状态码：`2xx` 成功、`3xx` 重定向、`4xx` 客户端问题、`5xx` 服务端问题。
- 用 `curl -v/-i` 观察请求和响应。

### 目标 2：理解 TCP 为什么可靠

- 理解端口、连接、socket 和文件描述符。
- 能讲清三次握手、四次挥手以及 `TIME_WAIT`。
- 理解序列号、确认号、超时重传、滑动窗口。
- 明白 TCP 是**字节流**，一次 `send` 不一定对应一次 `recv`；应用协议必须处理拆包、粘包。

### 目标 3：能区分 TCP、UDP 和常见网络问题

- 知道 TCP 的可靠性、顺序性、拥塞控制来自哪些机制。
- 知道 UDP 没有连接、重传和顺序保证，适合低延迟等场景。
- 会用 `ping`、`ip addr`、`ss`、`nslookup/dig`、`curl` 做基础排查。

### 目标 4：把网络知识接到 C++ 后端

- 用 Linux C++ socket 写 TCP 回显服务器和客户端。
- 正确处理 `socket`、`bind`、`listen`、`accept`、`connect`、`send/recv` 返回值。
- 理解阻塞、部分读写、对端关闭、错误处理和资源释放。
- 再学习多客户端、线程、`select/poll/epoll`，最后写一个极简 HTTP 服务器。

## 三、按顺序学习的目录

### 1. HTTP 入门

1. 请求和响应结构
2. 请求方法与状态码
3. 请求头、响应头、Cookie、Session
4. HTTP/1.1 长连接、分块传输
5. HTTPS：TLS 解决加密、身份验证、完整性

实验：`curl -v`、`curl -i`、`curl -X POST -H ... -d ...`。

### 2. DNS 与访问流程

1. 域名为什么需要 DNS
2. `getaddrinfo` 的作用
3. DNS 记录和缓存的基本概念
4. 从域名到 IP、端口、HTTP 的完整链路

实验：`nslookup` 或 `dig`，对比域名访问和 IP 访问。

### 3. TCP 基础与连接管理

1. TCP 与 UDP 的定位
2. 三次握手：确认双方收发能力和初始序列号
3. 四次挥手、半关闭、`TIME_WAIT`
4. 序列号、确认号、重传
5. 流量控制与拥塞控制
6. 字节流、拆包与粘包

实验：`ss -tnp` 观察监听、已连接和 `TIME_WAIT` 状态。

### 4. IP、路由与局域网

1. IPv4 地址和子网掩码
2. 默认网关与路由表
3. ARP、MAC、交换机的基本作用
4. ICMP 与 `ping`
5. NAT 为什么常见

实验：`ip addr`、`ip route`、`ping`、`traceroute`（环境支持时）。

### 5. Linux socket 编程

1. 文件描述符与 socket
2. TCP 服务端调用顺序：`socket -> bind -> listen -> accept`
3. TCP 客户端调用顺序：`socket -> connect`
4. `send/recv` 返回值和错误处理
5. 阻塞 IO、超时、关闭连接
6. 多线程、`select/poll`、`epoll`

实验：先写单客户端回显，再扩展到多客户端；每一步用 `ss` 和日志验证。
