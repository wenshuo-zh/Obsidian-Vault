## 写入策略

cache 与内存之间的数据同步：

- **写直达**：每次写入 cache 的同时立即写入主存
- **写回**：先把数据写到 Cache Block（缓存块）中，并添加脏块标记。脏 Cache 行写回主存一共有三种触发条件

## 脏 Cache 行写回主存的三种触发条件

1. **载入新行时 cache 满了，挤掉一行旧行**
   - 旧行是脏行：先写回主存，再覆盖
   - 旧行是干净行：直接丢弃（干净行和内存中数据一致）
     - **写命中**：要写的数据内存地址已经在 cache 中，直接在 cache 修改数据，同时打上脏标记，内存还是旧值
     - **写缺失**：cache 存的是别的内存的地址，要挤掉旧块，才能放进来新的数据
       - 旧块是脏的：把旧块写回主存，然后写分配（先把主存对应的整行载入 Cache 块，再在 Cache 里修改目标字节，最后打脏标记）
       - 旧块不是脏的：直接写分配
   - 单核只有缓存未命中而且旧块是脏的时候，才写回内存

2. **MESI 一致性协议**
   - Modified：已修改
   - Exclusive：独占
   - Shared：共享
   - Invalidated：已失效
