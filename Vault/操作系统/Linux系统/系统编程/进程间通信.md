# 管道
## 匿名管道pipe
```c
int pipefd[2]//管道两个文件描述符
pipe(pipefd)//创造匿名管道
```
`pipefd[0]`读端，读端接受数据
`pipefd[1]`写端
子进程写，父进程读的匿名管道示例：
```c
int main(int argc, char *argv[])
{
    int pipefd[2];
    pipe(pipefd);
    int pid = fork();
    if(pid == 0){
        close(pipefd[0]);//把自己管道读端关闭
        write(pipefd[1], "hello", 5);//往管道写端写内容
        close(pipefd[1]);//写完关闭自己写端
    }
    else{
        close(pipefd[1]);//父进程关闭写端
        char buf[32];
        int read_count = read(pipefd[0], buf, sizeof(buf));//读端读数据
        buf[read_count] = '\0';
        printf("read_count = %d, buf = %s\n", read_count, buf);
    }
    return 0;
}
```
![[Pasted image 20260930141139.png|676]]
- 管道没有数据：读端会堵塞，等待写端向管道写数据
- 管道已满：写端会堵塞，等待读端从管道读数据
- 写端全部关闭：读端正常读数据，读到管道为空触发EOF
- 读端全部关闭：调用写端会异常终止
## 命名管道FIFO
匿名管道只可以有亲缘关系的进程之间通信
命名管道有inode存在文件系统上，任意两个进程都可以打开通信
终端输入`mkfifo fifo`，创建一个管道文件，类型p
![[Pasted image 20260930142125.png]]
wfifo.c
```c 
int main(int argc, char *argv[])
{
    int fd = open("fifo", O_WRONLY);
    write(fd, "hello", 5);
    return 0;
}
```
rfifo.c
```c
int main(int argc, char *argv[])
{
    int fd = open("fifo", O_RDONLY);
    char buf[32];
    int read_count = read(fd, buf, sizeof(buf));
    buf[read_count] = '\0';
    printf("read_count = %d, buf = %s\n", read_count, buf);
    return 0;
}
```

# 内存映射
**mmap函数：**
`void *mmap(void *addr, size_t length, int prot, int flags, int fd, off_t offset);`
	addr：起始地址，通常设为NULL
	length：映射的长度
	prot：访问权限
		PROT_READ：可读取
		PROT_WRITE：可修改
	flags：
		MAP_SHARED：共享映射，其他共享映射的进程可见
		MAP_PRIVATE：私有映射，其他映射不可见
	fd：文件描述符，匿名映射为-1
	offest：偏移量，通常设为0，必须是分页大小的整数倍
**munmap函数：** 解除映射区域
`int munmap(void *addr, size_t length);`
## 匿名映射
在fork前mmap：父子进程共享一块物理内存
```c
int main(int argc, char *argv[])
{
    char *str = (char*)mmap(NULL, 64, PROT_READ | PROT_WRITE, MAP_SHARED | MAP_ANONYMOUS, -1, 0);
    pid_t pid = fork();
    if(pid == 0){
        strcpy(str, "hello");
        printf("child, str = %s\n", str);
    }else{
        sleep(1);
        printf("parent, str = %s\n", str);
        wait(NULL);
    }
    munmap(str, 64);
    return 0;
}
```

## 文件映射
实现两个无关进程间通信
两个进程虚拟地址不同，映射到磁盘上同一个文件a.txt的同一块物理内存
wmap.c
```c
int main(int argc, char *argv[])
{
    int fd = open("a.txt", O_RDWR | O_CREAT, 0664);
    ftruncate(fd, 64);
    char *str = (char*)mmap(NULL, 64, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    if(str == MAP_FAILED){
        perror("mmap error");
        close(fd);
        return -1;
    }
    int i = 0;
    while(1){
        sprintf(str,"===============%d", i++);//把格式化的字符串写入到共享内存中
        sleep(1);
    }
    return 0;
}
```

## 消息队列
mq_attr结构
```c
struct mq_attr{
	long mq_flags;//0堵塞；O_NONBLOCK非堵塞
	long mq_maxmsg;//队列最多存多少消息
	long mq_msgsize;//单条消息最大字节数
	long mq_curmsgs;//当前队列线程多少条消息（只读不可写）
}//msg：消息；mq：队列
```
`mqd`消息队列描述符
`mq_open()`在内核创建消息队列，返回消息队列描述符
`mq_getattr()`
	传两个参数：mqd和结构体attr的地址
	执行函数将当前队列的全部属性填进结构体
`mq_setattr()`
	传三个参数：mqd、newattr输入参数（新属性）、oldattr保存旧属性
	
```c
int main(int argc, char *argv[])
{
    mqd_t mqd = mq_open("/mymsg",O_RDONLY | O_CREAT, 0664, NULL);
    if(mqd == -1){
        perror("open mq");
        return -1;
    }
    struct mq_attr attr, newattr;
    mq_getattr(mqd, &attr);
    printf("mq_flags = %ld\n", attr.mq_flags);
    printf("mq_maxmsg = %ld\n", attr.mq_maxmsg);
    newattr.mq_flags = O_NONBLOCK;
    mq_setattr(mqd, &newattr, &attr);//attr被内核重写，里面存的是【修改之前】的值：{mq_flags=0, mq_maxmsg=10} 
// 注意：此时attr并不会自动变成修改后的2048！
    mq_getattr(mqd, &attr);// 再次查询，attr才更新为新值 {mq_flags=2048}
    printf("mq_flags = %ld\n", attr.mq_flags);
    return 0;
}
```

{
    mqd_t mqd = mq_open("/mymsg", O_RDONLY);

    mq_receive(mqd, buf, sizeof(buf), &prio);
