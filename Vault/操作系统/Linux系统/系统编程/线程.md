# 创建线程
需要有一个进程函数，进程的内容写在进程函数里面
`pthread_create()`
	成功返回0，失败返回错误号
	pthread \*thread 传出参数，，保存线程id
	const pthread_attr_t \*attr 属性，默认填NULL
	函数指针，一般填线程函数名
	arg 传的参数
`pthread_self()`
	返回线程id
```c
int a = 1;
void *thread(void *arg){
    printf("thread id = %ld\n", pthread_self());
    a = 0;
    return NULL;
}
int main(int argc, char *argv[])
{
    pthread_t tid;
    pthread_create(&tid, NULL, thread, NULL);
    printf("main return thread id = %ld\n", tid);
    sleep(1);
    printf("a = %d\n", a);
    return 0;
}
```

# 终止线程
## return
线程内部return，线程函数执行完毕，线程正常退出
如果线程函数里调用一个子函数，子函数 return，只是回到线程函数，线程继续跑，不会退出线程。
## pthread_exit()
立即结束当前线程，在哪里调用就在哪里退出，不限位置
只退出当前线程，不影响其他线程
## pthread_cancel(tid)
别的线程发起，发取消请求，不直接杀死，目标线程跑到取消点才终止
可以pthread_testcancel函数手动创建一个取消点
如果子进程走不到取消点，就算pthread_cancel()发了请求，也不会退出
```c
int a = 0;
void *thread(void *arg){
    while(1){
        a++;
        if(a == 100)a = 0;
    }
    pthread_testcancel();
    return NULL;
}
int main(int argc, char *argv[])
{
    pthread_t tid;
    pthread_create(&tid, NULL, thread, &a);
    pthread_cancel(tid);
    while(1){
        printf("a = %d\n", a);
        sleep(1);
    }
    return 0;
}
```

# 线程的连接与分离(回收线程资源)
## pthread_join()
一个线程等另一个线程，回收线程资源
	两个参数：thread为指定进程的id，\*retval为传出参数传线程返回值，不想要返回值传NULL
```c
void* thread(void* arg){
    sleep(3);
    return NULL;
}
int main(int argc, char *argv[])
{
    pthread_t tid;
    pthread_create(&tid, NULL, thread, NULL);
    pthread_join(tid, NULL);
    printf("dddz\n");
    return 0;
}
```
传NULL不要退出状态；堵塞，线程sleep三秒main等待阻塞，三秒后main才继续向下走打印dddz
```c
void* thread(void* arg){
    sleep(3);
    return NULL;
}
int main(int argc, char *argv[])
{
    pthread_t tid;
    pthread_create(&tid, NULL, thread, NULL);
    void *retval;
    pthread_join(tid, &retval);
    printf("retval: %s\n", (char*)retval);
    return 0;
}
```
获取退出状态

## pthread_detach()
不关心返回状态，系统在线程终止时能够自动清理并移除
一旦线程成功 detach（分离态），就不能再调用 `pthread_join` 去连接它，`pthread_join` 会直接返回失败。
