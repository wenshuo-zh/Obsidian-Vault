# inode，block
- inode和block在外存（磁盘），inode和block共同协作存一个文件
- inode存文件元数据：文件权限、大小、时间，block的索引指针，硬链接计数，文件类型
- block存文件真实内容（一个文件可以占用多个block）

# 硬链接和软连接
## 硬链接（Hard Link）
	ln 源文件 目标文件
- 和源文件共有一个inode和block；不会新建inode和数据block，但目录中会新增一个目录项，占用少量目录空间
- 目录项保存inode编号
- 删除源文件硬链接计数-1，仍能访问文件内容；硬链接计数为0且没有进程打开该文件时，才真正回收inode和block
- 对硬链接读写，实际操作的是同一个inode和block，多个文件名指向同一个文件对象
- 不能跨文件系统；不能对目录创建硬链接，可能产生环、图
## 软连接（Symbolic Link）
	 ln -s 源文件 目标文件
- 新建一个inode，本身是一个独立文件（很小）
- 存目标文件的路径，可以是绝对路径，也可以是相对路径
- 删除源文件，软连接无法访问
- 删除软连接本身不会删除目标文件；删除目标文件后，软连接会变成悬空链接
- 对软连接读写，系统会转换对源文件的操作
- 可以跨文件系统，可以对目录创建软连接
