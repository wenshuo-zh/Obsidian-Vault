## 编译阶段

`test.c` ->
**预处理** -> `test.i(预处理文件)` -> 
**编译** -> `test.s(汇编文件)` ->
**汇编** ->`test.o(机器码文件)` ->
**链接** -> 
可执行文件

如果跳步骤就会把连带把之前的步骤执行了
- 预处理：头文件展开，宏替换，删除注释
- 编译：语法词法分析，得到汇编语言
- 汇编：翻译汇编指令成二进制机器码、生成符号表
- 链接：重定位，符号解析
