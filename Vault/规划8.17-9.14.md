# 四周学习规划

> 学习目标：C++ 后端方向 学习主线：代码随想录 + C++ Primer (第 5 版) + 小林图解操作系统 + Linux 实操 辅助工具：Obsidian 笔记归档 | ClaudeCode + DeepSeek V4-Flash 每日固定时长
> 
> - 代码随想录：2.5 h
> - C++ Primer：1.2 h
> - 操作系统 + Linux 实操：1.5 h 单日有效学习合计：5.2 h

> 通用执行准则
> 
> 1. 算法先独立思考，禁止直接抄写题解；思路、坑点、AC 代码全部存档
> 2. Primer 遵循「刷题驱动看书」，遇到语法 / STL 卡点立刻查阅书本
> 3. OS 概念尽量在 Linux (WSL) 编写小段 C++ 代码、使用命令验证，不要只看书
> 4. 所有知识点做好笔记，建立双向链接
> 5. 普通任务使用 V4-Flash；复杂算法推导、大型代码重构临时切换 V4-Pro

## 第 1 周

### 代码随想录

板块：数组专题全部题目 每日任务：平均 2 题 核心重点：二分查找、滑动窗口、双指针；理解数组内存连续特性 打卡验收：独立写出模板，能区分各类区间边界易错点

### C++ Primer

阅读范围：第 1～5 章

1. 程序基础
2. 变量和基本类型（重点：引用、const、auto）
3. string、vector、内置数组
4. 表达式、运算符优先级与短路特性
5. 分支、循环语句 目标：熟练使用 vector 替代原生数组，吃透引用基础语法



### 小林图解操作系统

学习范围：进程基础 进程概念、进程状态、PID、父子进程、fork 基础 Linux 实操：`ps top pstree`；编写简易 fork 测试 C++ 代码

### 本周收尾自查清单

- 数组所有题目完成复盘
- Primer 1～5 章习题、示例代码手动运行
- 能够用代码创建子进程，区分父子进程执行逻辑

---

## 第 2 周

### 代码随想录

板块：链表专题全部题目 每日任务：平均 2 题 核心重点：虚拟头结点、链表反转、环形链表、快慢指针、链表相交

### C++ Primer

阅读范围：第 6、7 章 第 6 章 函数：值传递 / 引用传递、重载、inline、默认参数 第 7 章 类基础：成员、访问控制、构造函数、this 指针 暂跳过：友元、复杂静态成员（简单了解即可）

### 小林图解操作系统

学习范围：线程、进程通信基础 进程与线程区别、上下文切换、资源隔离；管道通信基础 Linux 实操：pthread 简单多线程代码；观察多线程共享全局变量

### 本周收尾自查清单

- 链表各类题型模板整理完毕
- 掌握引用传参场景，能写出基础自定义类与构造函数
- 清晰区分进程、线程资源隔离差异

---

## 第 3 周

### 代码随想录

板块：哈希表专题全部题目 每日任务：平均 2 题 核心重点：set /map/unordered_map 使用场景、哈希查找思想、去重问题

### C++ Primer

阅读范围：第 8（简略浏览）、9、10 章 第 8 章 IO 库：粗略浏览，不深究格式化 第 9 章 顺序容器：vector deque；迭代器失效（高频笔试考点） 第 10 章 泛型算法：sort、find 等常用算法

### 小林图解操作系统

学习范围：内存管理开篇 虚拟内存概念、进程内存布局：栈、堆、全局数据区 联动 C++：理解 new/delete 在堆上分配内存 Linux 实操：简单测试堆内存分配，观察内存分布

### 本周收尾自查清单

- 能够根据场景选择有序容器 / 哈希容器
- 掌握迭代器失效典型场景
- 分清程序栈内存、堆内存生命周期

---

## 第 4 周

### 代码随想录

板块：字符串专题全部题目 每日任务：平均 2 题 核心重点：字符串双指针、字符串匹配、KMP 基础

### C++ Primer

阅读范围：第 11、12 章 第 11 章 关联容器 map unordered_set 第 12 章 动态内存 new /delete；shared_ptr 基础概念 暂跳过：自定义分配器

### 小林图解操作系统

学习范围：分页、缺页中断、死锁 分页机制、缺页异常；死锁四大必要条件、死锁预防与避免 拓展思考：多线程场景下锁竞争引发死锁（为后续服务器项目铺垫）

### 本周收尾自查清单

- 字符串常见题型熟练掌握
- 理解裸指针风险，了解智能指针解决思路
- 能够举例说明死锁产生条件与规避方式

---

## 四周整体完成标准

1. 算法：数组 → 链表 → 哈希表 → 字符串全部完成，具备基础笔试编码能力
2. C++ Primer：吃透基础语法、函数、类、顺序 / 关联容器、动态内存，刷题语法障碍大幅减少
3. 操作系统：掌握进程线程、虚拟内存、内存布局、死锁基础，可以看懂基础 Linux 多进程 / 多线程代码

## 四周之后衔接路线预告

1. 算法：栈与队列 → 二叉树（体量最大模块）
2. C++ Primer：第 13 章 拷贝控制（浅拷贝、深拷贝、三五法则）
3. 操作系统：信号、IO 模型、阻塞 / 非阻塞 IO、epoll（后端重中之重）
