# 008|【3】无重复字符的最长子串
## 滑动窗口+哈希表
用哈希表记录字符上一次出现的位置。遍历到 `right` 时，如果该字符上次出现的位置仍在当前窗口内，就将 `left` 移到该位置的后一位；否则窗口左边界不变。
```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<char, int> mp;//键存字符，值存上一次出现的下标
        int left = 0;
        int res = 0;
        for(int right = 0; right < s.size(); right++){
            //找到了，且上次位置在窗口左边界右边
            if(mp.find(s[right]) != mp.end() && mp[s[right]] >= left){
                left = mp[s[right]] + 1;
            }
            mp[s[right]] = right;
            res = max(res, right-left + 1);
        }
        return res;
    }
};
```
时间复杂度：平均 O(n)
空间复杂度：O(min(n, |Σ|))，Σ为字符集
# 009|【438】找到字符串中所有字母异位词
```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        unordered_map<char, int> pmp;
        unordered_map<char, int> smp;
        vector<int> res;
        if (p.size() > s.size()) return res;
        // 初始化窗口
        for (int i = 0; i < p.size(); i++) {
            pmp[p[i]]++;
            smp[s[i]]++;
        }
        if (pmp == smp) res.push_back(0);
        // 滑动窗口
        for (int left = 0; left < s.size() - p.size(); left++) {
            // 移出左边字符
            smp[s[left]]--;
            if (smp[s[left]] == 0) smp.erase(s[left]);
            // 加入新的右边字符
            int right = left + p.size();
            smp[s[right]]++;
            
            if (pmp == smp) {
                res.push_back(left + 1);
            }
        }
        return res;
    }
};
```
时间复杂度：O(n)，题目限定小写字母，每个窗口最多比较 26 个键
空间复杂度：O(1)
