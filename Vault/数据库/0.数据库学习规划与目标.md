# 数据库学习规划与目标

> 面向 C++ 后端求职的 15 天数据库入门路线。目标是掌握 MySQL 核心原理，能写出可靠 SQL，能分析基础性能问题，并把数据库接入 C++ 后端程序。

## 学习维护规则

- 每天按“概念讲解 -> 自己复述 -> SQL/命令实验 -> 记录结果”推进。
- 复述有错误时，先纠正理解，再更新笔记和任务进度。
- 实验没有实际运行，不把任务标记为完成。
- 每天只完成当天核心目标，超出范围的内容记为后续，不强行扩展。

## 半个月完成目标

完成后应能够：

1. 独立设计用户、商品、订单等基础表；
2. 熟练完成增删改查、多表连接、分组和分页查询；
3. 使用 `EXPLAIN` 分析简单查询和索引是否生效；
4. 解释事务、隔离级别、MVCC、行锁和常见死锁；
5. 用 C++ 连接 MySQL，正确处理资源、错误和事务；
6. 解释 Redis 的缓存作用，并处理缓存穿透、击穿和雪崩的基本思路；
7. 完成一个“用户/商品/订单”小型数据库实践。

## 学习边界

### 必须掌握

- SQL 基础和表结构设计
- 主键、外键、约束和范式的基本取舍
- B+ 树索引、联合索引、覆盖索引、回表
- `EXPLAIN` 基础字段和慢查询定位
- ACID、隔离级别、MVCC、行锁和死锁
- C++ MySQL API、RAII、连接池和事务封装
- Redis 数据结构、过期策略和缓存问题

### 只做了解

- 主从复制、读写分离和分库分表
- Binlog、Redo Log、Undo Log 的整体作用
- Redis 集群、哨兵和持久化细节

这些内容不作为 15 天内的完成条件。

## 15 天路线

| 天数 | 主题 | 实验或产出 |
| --- | --- | --- |
| 第 1 天 | 数据库、MySQL、表和基本命令 | 安装/检查 MySQL，创建数据库和用户 |
| 第 2 天 | 表设计、数据类型、约束 | 创建用户、商品、订单表 |
| 第 3 天 | 增删改查与条件查询 | 完成基础 CRUD 和边界数据测试 |
| 第 4 天 | 聚合、分组、排序、分页 | 写统计和分页 SQL |
| 第 5 天 | 多表连接与子查询 | 查询用户订单、商品销量 |
| 第 6 天 | 索引和 B+ 树 | 建索引并用 `EXPLAIN` 对比 |
| 第 7 天 | 联合索引与查询优化 | 验证最左匹配、覆盖索引和回表 |
| 第 8 天 | 事务和 ACID | 提交、回滚和并发现象实验 |
| 第 9 天 | 隔离级别与 MVCC | 观察脏读、不可重复读和幻读边界 |
| 第 10 天 | 锁与死锁 | 观察行锁、锁等待，整理排查方法 |
| 第 11 天 | C++ 访问 MySQL | 完成连接、查询、参数绑定和错误处理 |
| 第 12 天 | C++ 连接池与 RAII | 实现简化连接池和自动归还连接 |
| 第 13 天 | Redis 基础 | 完成 String/Hash/List/Set/ZSet 实验 |
| 第 14 天 | Redis 缓存问题 | 实现缓存读写，整理穿透/击穿/雪崩 |
| 第 15 天 | 综合复盘与项目 | 完成小项目、面试复述和问题清单 |

## 项目完成标准

使用 MySQL 保存用户、商品和订单数据；使用 Redis 缓存热点商品或用户信息；C++ 通过连接池访问 MySQL；至少包含一次事务；用 `EXPLAIN` 分析一个查询；记录错误处理和资源释放方式。

## 推荐复盘问题

- 为什么不能把所有字段都建索引？
- 联合索引 `(a, b, c)` 在哪些条件下能使用？
- 事务隔离级别解决了什么问题？
- 数据库行锁和 C++ 互斥锁分别保护什么？
- Redis 挂掉后，业务如何保证数据最终可靠？
