## 三、Windows 环境检查与安装

### 1. 检查 MySQL 服务和客户端

打开 **PowerShell**，执行：

```powershell
mysql --version
Get-Service -Name 'MySQL*'
```

正常情况：

- `mysql --version` 会显示客户端版本；
- 服务名称通常是 `MySQL80`，状态应为 `Running`；
- 如果 PowerShell 找不到 `mysql`，不代表 MySQL 一定没有安装，可能只是客户端目录未加入 `PATH`。

### 2. 未安装时的操作

安装 MySQL Community Server for Windows，并在安装向导中：

1. 选择安装 **MySQL Server 8.x**；
2. 设置并妥善保存 `root` 密码；
3. 保持默认端口 `3306`；
4. 将 MySQL 配置为 Windows 服务，并设置为自动启动；
5. 可选安装 MySQL Workbench，但今天优先使用命令行。

安装完成后，重新打开 PowerShell，执行：

```powershell
Get-Service -Name 'MySQL*'
```

服务未启动时，使用实际服务名启动。常见名称为 `MySQL80`：

```powershell
Start-Service -Name MySQL80
Get-Service -Name MySQL80
```

### 3. 登录 MySQL

在 PowerShell 中执行：

```powershell
mysql -u root -p
```

输入安装时设置的 `root` 密码，成功后会看到 `mysql>` 提示符。注意：

- `mysql -u root -p` 是 Windows PowerShell 命令；
- `SHOW DATABASES;` 是 MySQL SQL 语句；
- SQL 语句通常以分号 `;` 结束；
- 退出 MySQL 使用 `EXIT;` 或 `\\q`。

如果 `mysql` 提示“不是内部或外部命令”，先在资源管理器中查找 `mysql.exe`，常见目录为：

```text
C:\Program Files\MySQL\MySQL Server 8.0\bin
```

进入该目录后重新执行：

```powershell
cd 'C:\Program Files\MySQL\MySQL Server 8.0\bin'
.\mysql.exe -u root -p
```

## 四、创建学习数据库

进入 MySQL 后逐条执行：

```sql
SHOW DATABASES;

CREATE DATABASE backend_learning
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;

USE backend_learning;

SELECT DATABASE();
SHOW TABLES;
```

自测：

1. `SHOW DATABASES;` 能看到 `backend_learning`；
2. `SELECT DATABASE();` 输出当前数据库名；
3. 新数据库刚创建时，`SHOW TABLES;` 应该暂时没有业务表。

## 五、创建第一张表

创建用户表：

```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    age INT,
    email VARCHAR(100),
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

查看表结构：

```sql
SHOW TABLES;
DESC users;
SHOW CREATE TABLE users;
```

字段含义：

| 字段 | 含义 |
| --- | --- |
| `id` | 用户编号，主键，自动递增 |
| `username` | 用户名，不能为空且不能重复 |
| `age` | 年龄，可以暂时没有值 |
| `email` | 邮箱，可以暂时没有值 |
| `created_at` | 创建时间，未指定时使用当前时间 |

## 六、插入数据

先插入正常数据：

```sql
INSERT INTO users (username, age, email)
VALUES ('zhangsan', 25, 'zhangsan@example.com');

INSERT INTO users (username, age, email)
VALUES
    ('lisi', 30, 'lisi@example.com'),
    ('wangwu', NULL, NULL),
    ('zhaoliu', 22, 'zhaoliu@example.com');
```

查看数据：

```sql
SELECT * FROM users;
SELECT id, username, age FROM users;
```

重点观察：`id` 和 `created_at` 没有手动填写，但数据库自动生成了它们。

## 七、查询、修改和删除

### 1. 条件查询

```sql
SELECT * FROM users WHERE age >= 25;
SELECT * FROM users WHERE email IS NULL;
SELECT * FROM users WHERE username = 'lisi';
```

`NULL` 不能使用 `= NULL` 判断，必须使用 `IS NULL` 或 `IS NOT NULL`。

### 2. 排序和限制数量

```sql
SELECT * FROM users ORDER BY age ASC;
SELECT * FROM users ORDER BY created_at DESC LIMIT 2;
```

### 3. 修改数据

```sql
UPDATE users
SET age = 26
WHERE username = 'zhangsan';

SELECT * FROM users WHERE username = 'zhangsan';
```

执行 `UPDATE` 前先写同样条件的 `SELECT`，确认影响范围正确。

### 4. 删除数据

```sql
DELETE FROM users
WHERE username = 'zhaoliu';

SELECT * FROM users;
```

不要在还不了解影响范围时执行没有 `WHERE` 的 `UPDATE` 或 `DELETE`。

## 八、必须完成的错误练习

每组执行后记录错误原因，不要只看结果：

```sql
-- 1. 重复用户名，应触发唯一约束错误
INSERT INTO users (username) VALUES ('zhangsan');

-- 2. 缺少用户名，应触发 NOT NULL 错误
INSERT INTO users (age) VALUES (18);

-- 3. 错误判断 NULL，观察为什么查不到 wangwu
SELECT * FROM users WHERE email = NULL;

-- 4. 正确判断 NULL
SELECT * FROM users WHERE email IS NULL;
```
