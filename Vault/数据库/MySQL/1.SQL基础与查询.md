# 一、基础查询与条件查询
## 基础查询 select
```sql
#查询整张表
select * from employees;
#查询指定字段
select emp_name,salary from employees;
```
## 条件查询 where
```sql
#等于用 = 不等于用<> 或者 !=
select * from employees where salary > 10000;

#组合条件 and or
select * from employees where salary >= 10000 and dept_id = 2;

#between and 范围查询(包含边界)
select * from employees where salary between 10000 and 15000;

#in 包含多个指定值
select * from employees where dept_id in (1, 3);

#like 模糊查询
# '张%' 任意长度  '张_'一个字符  '%张%'任意位置
select * from employees where emp_name like '张%';

#is null 判断空值  is not null 判断非空
select * from employees where dept_id is null;
```
- `or` 或  `and` 与
- `not in()` 不包含null 如需要查询时加上`or` `is null` 
# 二、排序、去重与分页
## 排序 order by
	asc 升序，desc降序 
	order by通常放查询语句最后
```sql
#排序 order by（asc 升序，desc降序）
select * from employees order by salary desc;
#多字段排序
select * from employees order by salary desc, hire_date asc;#(先按工资降序，如相同按入职日期升序)
```
## 去重 distinct
```sql
#去重 distinct
select distinct dept_id from employees;
#多字段去重（去重组合）
select distinct dept_id ,gender from employees;
```
## 分页 limit
```sql
#分页 limit
select emp_name, salary from employees order by salary desc limit 3;
#offset 3 跳过前3条
select emp_name, salary from employees order by salary desc limit 3 offset 3;
#简写
select emp_name, salary from employees order by salary desc limit 3, 3;
```
# 三、增，改，删
## 插入数据 insert
```sql
insert into employees 
  (emp_name, dept_id, salary, gender, hire_date, email)
values
  ('刘明', 5, 28000, 'M', '2026-10-28', 'liuming@qq.com');
```
## 修改数据 update
```sql
#修改数据 update 表名 set
update employees set salary = 29999 where emp_name = '刘明';
```
## 删除数据 delete
```sql
#删除数据 delete
delete from employees where emp_name = '刘明';
```
不加where条件整个表里的数据都被删除
### 区分delete、truncate、drop
| 语句         | 删除数据       | 删除表结构 | 能否用 `WHERE` |     |
| ---------- | ---------- | ----- | ----------- | --- |
| `DELETE`   | 可以删除部分或全部行 | 不删除   | 可以          | DML |
| `TRUNCATE` | 删除表内全部数据   | 不删除   | 不可以         | DML |
| `DROP`     | 表数据随表一起消失  | 删除    | 不可以         | DDL |
```sql
truncate table employees;
drop table employees;
```
- DDL 定义或修改表结构
- DML 操作表中的数据
- DQL 查询数据
# 四、建表与约束
## 常用数据类型
`char(n)` 固定长度字符串
`varchar(n)` 可变长度字符串
`decimal(m, n)` 精确小数 最多m位数字，其中小数点后保留n位
`date` 日期
`datetime` 日期和时间
`text` 长文本
## 建表 create table
```sql
#建表
create table product(
  id int,
  name varchar(100),
  price decimal(8, 2),
  create_date date
);
```
## 主键 primary key
==唯一且非空== ==一张表只能有一个主键==
```sql
create table product(
  id int primary key, #主键
  name varchar(100) unique, #唯一约束
  price decimal(8, 2),
  create_date date
);
```
其他的非主键字段想唯一约束用`unique`
### 其他约束
`unique` 唯一约束
`not null` 非空约束
`default n` 设定默认值为n
```sql
create table product(
  id int primary key,
  product_name varchar(100) unique not null,
  price decimal(8, 2),
  status int default 1
);
```
## 外键 
**foreign key(字段) references 表2(字段)**
维护表之间的关联
```sql
create table department(
  id int primary key,
  dept_name varchar(100) not null
);
create table employee(
  id int primary key,
  name varchar(100) not null,
  dept_id int,
  foreign key(dept_id) references department(id) #外键
);
```
`foreign key(dept_id) references department(id)` 
员工表的部门编号设置为外键关联部门表的id
# 五、常见函数
## 字符串函数
`upper()` 英文字母转大写

`length()` 字符串字节数

## 数值函数

`abs()` 取绝对值
`ceil()` 向上取整
`floor()` 向下取整

## 处理null  ifnull()
`ifnull(要检查的值, 如果为NULL就替换成什么)`
## 多条件判断 case when
```sql
select emp_name, salary, 
  case
    when salary >= 15000 then '高级员工'
    when salary >= 10000 then '中级员工'
    else '普通员工'
  end as level #结果列起名叫level
from employees;
```
