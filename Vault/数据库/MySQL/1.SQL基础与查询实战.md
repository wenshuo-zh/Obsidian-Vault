# 一、基础查询与条件查询
## 基础查询 select
```sql
#查询整张表
select * from employees;
#查询指定字段
select emp_name,salary from employees;
```
## 条件查询 where
```sql
#等于用 = 不等于用<> 或者 !=
select * from employees where salary > 10000;

#组合条件 and or
select * from employees where salary >= 10000 and dept_id = 2;

#between and 范围查询(包含边界)
select * from employees where salary between 10000 and 15000;

#in 包含多个指定值
select * from employees where dept_id in (1, 3);

#like 模糊查询
# '张%' 任意长度  '张_'一个字符  '%张%'任意位置
select * from employees where emp_name like '张%';

#is null 判断空值  is not null 判断非空
select * from employees where dept_id is null;
```
- `or` 或  `and` 与
- `not in()` 不包含null 如需要查询时加上`or` `is null` 
# 二、排序、去重与分页
## 排序 order by
	asc 升序，desc降序 
	order by通常放查询语句最后
```sql
#排序 order by（asc 升序，desc降序）
select * from employees order by salary desc;
#多字段排序
select * from employees order by salary desc, hire_date asc;#(先按工资降序，如相同按入职日期升序)
```
## 去重 distinct
```sql
#去重 distinct
select distinct dept_id from employees;
#多字段去重（去重组合）
select distinct dept_id ,gender from employees;
```
## 分页 limit
```sql
#分页 limit
select emp_name, salary from employees order by salary desc limit 3;
#offset 3 跳过前3条
select emp_name, salary from employees order by salary desc limit 3 offset 3;
#简写
select emp_name, salary from employees order by salary desc limit 3, 3;
```
# 三、增，改，删
## 插入数据 insert
```sql
insert into employees 
  (emp_name, dept_id, salary, gender, hire_date, email)
values
  ('刘明', 5, 28000, 'M', '2026-10-28', 'liuming@qq.com');
```
## 修改数据 update
```sql
#修改数据 update 表名 set
update employees set salary = 29999 where emp_name = '刘明';
```
## 删除数据 delete
```sql
#删除数据 delete
delete from employees where emp_name = '刘明';
```
不加where条件整个表里的数据都被删除
### 区分delete、truncate、drop
| 语句         | 删除数据       | 删除表结构 | 能否用 `WHERE` |     |
| ---------- | ---------- | ----- | ----------- | --- |
| `DELETE`   | 可以删除部分或全部行 | 不删除   | 可以          | DML |
| `TRUNCATE` | 删除表内全部数据   | 不删除   | 不可以         | DML |
| `DROP`     | 表数据随表一起消失  | 删除    | 不可以         | DDL |
```sql
truncate table employees;
drop table employees;
```
- DDL 定义或修改表结构
- DML 操作表中的数据
- DQL 查询数据
