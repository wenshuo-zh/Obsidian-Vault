# 9.27-10.7 学习规划：数据库、计算机网络与算法

## 基于实际进度的调整

### 已完成进度

- **算法**：已完成数组、链表、哈希表、字符串、二叉树、BST、回溯；贪心已完成分发饼干、摆动序列、最大子数组和、买卖股票的最佳时期 II。
- **操作系统/Linux**：已完成硬件结构、虚拟内存、内存管理、进程线程、调度、IPC、死锁、Linux 基础命令、文件权限、编译链接、I/O 与进程。
- **C++ Primer**：当前笔记进度到第 2 章。
- **数据库、计算机网络**：笔记库中尚未开始，属于本阶段的新增主线。

### 调整结论

原规划将 9.21-10.18 的重点放在计算机网络、Socket 和工程化，并将 MySQL/Redis 放到 10.19 之后。现在按实际需求调整为：

1. 这 11 天只推进 **MySQL 基础 + 计算机网络基础 + 算法**，不新增 C++ Primer、操作系统或项目主线。
2. 数据库先覆盖 MySQL 的 SQL、索引、事务、MVCC、锁和 `EXPLAIN`；**Redis 暂不纳入本轮**，避免数据库基础没打牢就分散精力。
3. 网络重点放在 TCP、HTTP/HTTPS、Socket 与 I/O 多路复用；其中 epoll 只和已学 I/O 知识建立联系，不提前深入源码或启动大型项目。
4. 算法按当前进度继续：**完成贪心 -> 动态规划入门**，每天复习一道旧题，防止已学专题遗忘。

## 每日时间结构（6-7 小时）

| 模块 | 时长 | 完成标准 |

## 每日计划

| 日期 | 数据库 / 网络（3.5h） | 算法（2h） | 当日验收 |
|---|---|---|---|
| **9.27** | MySQL 概览：关系型数据库、库表、字段类型、主键/外键；SQL：`CREATE`、`INSERT`、`SELECT`、`UPDATE`、`DELETE` | 贪心：跳跃游戏、K 次取反后最大化数组和 | 建一张“用户表”，写 10 条基础 SQL；能说明主键和普通索引区别 |
| **9.28** | SQL 查询：`WHERE`、排序、聚合、`GROUP BY/HAVING`、多表 `JOIN`；理解一条 SQL 在 MySQL 中的执行流程 | 贪心：加油站、分发糖果；复习三数之和 | 手写内连接、左连接 SQL；画 SQL 执行流程 |
| **9.29** | 索引：B+ 树、聚簇索引、二级索引、回表、覆盖索引、最左匹配原则 | 贪心：柠檬水找零、根据身高重建队列 | 能回答“为什么 MySQL 使用 B+ 树而非红黑树/Hash” |
| **9.30** | 索引优化：索引失效场景、联合索引、`EXPLAIN` 重点字段、慢查询定位 | 贪心：区间问题（无重叠区间、划分字母区间） | 整理至少 8 条索引失效情形；会读 `type`、`key`、`rows` |
| **10.1** | 事务：ACID、隔离级别、脏读/不可重复读/幻读；MVCC、Read View、undo log | 贪心收尾：合并区间；本专题限时复盘 3 题 | 不看资料解释 MVCC 如何解决不可重复读 |
| **10.2** | 锁与事务进阶：行锁、表锁、间隙锁、临键锁、死锁；事务与索引的关系 | 动态规划入门：斐波那契数、爬楼梯、使用最小花费爬楼梯 | 能说明死锁四条件、常见解决方式；写出 DP 五步法 |
| **10.3** | 网络基础：TCP/IP 四层模型、封装/解封装、IP、端口、DNS、从输入 URL 到页面展示 | DP：不同路径、不同路径 II；复习二叉树层序遍历 | 画出浏览器访问 HTTPS 网站的完整链路 |
| **10.4** | TCP 建连与断连：三次握手、四次挥手、`TIME_WAIT`、`CLOSE_WAIT`、半关闭 | DP：整数拆分、不同的二叉搜索树 | 能解释“为什么握手三次、挥手四次、TIME_WAIT 要等待” |
| **10.5** | TCP 可靠传输：序列号/确认号、滑动窗口、流量控制、超时重传、快速重传、拥塞控制；TCP 与 UDP 对比 | DP：0/1 背包理论与二维 DP | 区分流量控制和拥塞控制；写出 0/1 背包状态定义与转移 |
| **10.6** | HTTP/HTTPS：HTTP 版本、请求/响应结构、常用状态码、Cookie/Session/JWT、缓存；TLS 握手 | DP：0/1 背包一维优化、分割等和子集 | 能完整说明 HTTPS 如何同时保证加密、完整性和身份认证 |
| **10.7** | Socket 与服务端基础：阻塞/非阻塞 I/O、`select/poll/epoll` 的问题与区别；数据库+网络综合复盘 | 算法周测：贪心 2 题 + DP 2 题，复盘错题 | 进行 30 分钟模拟面试：MySQL 10 问、网络 10 问；输出薄弱点清单 |

## 执行建议

1. **本轮不追求学完小林全部内容。** 11 天的目标是形成可用于面试和项目的第一轮知识框架。
2. **数据库优先于 Redis。** 能讲清索引、事务、MVCC、锁和 SQL 优化后，再学 Redis 的缓存一致性问题。
3. **网络优先 TCP 与 HTTP/HTTPS。** 这是后端实习面试的核心；Socket 和 epoll 作为项目理论入口即可。
4. **每天算法必须有旧题复习。** 新专题 DP 容易挤掉已学内容，旧题至少保留 30 分钟。
5. 若当天时间不足，保底完成：数据库/网络核心小节 90 分钟 + 算法 1 题 + 20 分钟口述复盘；不要用周末无上限补课。
